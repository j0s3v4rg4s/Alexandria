# mapcn — Componentes de Mapa para React

## Qué es

mapcn es una librería open-source de componentes de mapa listos para usar en React. Gratuitos, sin configuración, y se instalan con un solo comando. Piensa en shadcn/ui pero para mapas.

## Para qué sirve

- Agregar mapas interactivos a aplicaciones React/Next.js sin complicaciones
- Crear UIs con mapas de forma declarativa y composable
- Tener mapas con tema claro/oscuro automático
- Integrar marcadores, popups, rutas, controles de zoom, brújula, etc.

## Características principales

- 🎨 **Theme-aware** — Se adapta automáticamente a light/dark mode
- 🎯 **Zero config** — Funciona out of the box con defaults sensatos
- 📦 **Compatible con shadcn/ui** — Mismos patrones y convenciones de estilo
- 🗺️ **MapLibre GL** — Acceso completo a las capacidades de MapLibre
- 🧩 **Composable** — Construye UIs complejas con componentes simples y declarativos
- 📍 **Markers & Popups** — Sistema de marcadores con popups, tooltips y labels
- 🛤️ **Routes** — Dibuja rutas y caminos en los mapas
- 🎮 **Controls** — Zoom, brújula, locate y fullscreen

## Stack

- **Motor:** MapLibre GL
- **Estilos:** Tailwind CSS
- **Patrón:** shadcn/ui compatible
- **Basemaps:** CARTO (OpenStreetMap data) — o cualquier tile provider compatible con MapLibre

## Instalación

```bash
# Un solo comando para agregar componentes
npx mapcn add basic-map
```
