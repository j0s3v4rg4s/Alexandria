# SkillsMP — Agent Skills Marketplace

## Qué es

SkillsMP es un marketplace con una mega colección de **Agent Skills** para mejorar agentes de IA. Son paquetes de conocimiento en formato Markdown que le enseñan a los agentes a realizar mejor tareas específicas.

## Para qué sirve

- Buscar y descargar skills especializados para distintos agentes de IA
- Mejorar las capacidades de agentes como **Claude Code**, **Visual Studio Code**, **Antigravity**, entre otros
- Acceder a conocimiento curado y estructurado en formato Markdown que los agentes pueden consumir directamente
- Encontrar skills para tareas específicas: desarrollo, DevOps, escritura, análisis, etc.

## Números

- **+60.000 skills** disponibles en el catálogo
- Soporte para múltiples plataformas de agentes

## Agentes compatibles

- Claude Code
- Visual Studio Code (Copilot)
- Antigravity
- Y más...

## Cómo usar

1. Visitar el buscador: [skillsmp.com/es/search](https://skillsmp.com/es/search)
2. Buscar por palabra clave o categoría
3. Descargar el skill (archivo `.md`)
4. Colocarlo en la carpeta de skills del agente correspondiente (ej: `.cursor/skills/`, `.claude/skills/`, etc.)

## Formato de los Skills

Los skills son archivos Markdown con estructura estándar:
- **Nombre y descripción** del skill
- **Instrucciones** que el agente debe seguir
- **Referencias** y ejemplos
- **Scripts** auxiliares (cuando aplica)
