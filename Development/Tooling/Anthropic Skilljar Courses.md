# Anthropic Skilljar Courses

## Qué es
**Plataforma de cursos gratuitos de Anthropic** para aprender y dominar el uso de IA en desarrollo de software. Incluye formación oficial sobre Claude, la API de Anthropic, MCP (Model Context Protocol) y mejores prácticas para trabajar con IA. Todos los cursos incluyen **certificado de finalización**.

## Para qué sirve
- Aprender a integrar Claude en tu workflow de desarrollo
- Dominar el uso de la Claude API de forma práctica
- Entender y aplicar Model Context Protocol (MCP)
- Establecer bases sólidas para trabajar con IA de manera efectiva
- Obtener certificaciones oficiales de Anthropic

## Cursos disponibles

### 🧑‍💻 Claude Code en tu workflow
Integración práctica de Claude Code en el desarrollo diario:
- Configuración y setup inicial
- Comandos y atajos esenciales
- Mejores prácticas de uso
- Casos de uso reales

### 🔌 Uso real de la Claude API
Guía práctica para desarrolladores sobre la API de Claude:
- Autenticación y configuración
- Endpoints y parámetros
- Rate limits y optimización
- Manejo de errores
- Ejemplos de código en diferentes lenguajes
- Integración en aplicaciones reales

### 🔗 Introducción a MCP (Model Context Protocol)
Fundamentos del protocolo de contexto para modelos:
- Qué es MCP y por qué es importante
- Casos de uso y aplicaciones
- Implementación básica
- Mejores prácticas

### 📚 Bases para trabajar con IA
Fundamentos esenciales para desarrollo con IA:
- Prompt engineering efectivo
- Manejo de contexto
- Limitaciones y capacidades de LLMs
- Seguridad y privacidad
- Evaluación de resultados
- Debugging de respuestas de IA
