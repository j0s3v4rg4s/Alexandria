# SVGL

## Qué es
SVGL es una **biblioteca abierta de logos en formato SVG**, curada y optimizada para uso directo en proyectos web. Actualmente cuenta con **581 logos** de marcas, tecnologías, frameworks y servicios populares.

## Para qué sirve
- Obtener logos SVG de alta calidad sin tener que buscarlos manualmente
- Usar logos optimizados y listos para producción en tus proyectos
- Copiar directamente el código SVG o integrarlo como componente en tu framework favorito
- Ahorrar tiempo en diseño de landing pages, documentación, portfolios y dashboards

## Formatos disponibles
- **SVG puro** — copiar/pegar directo
- **React** — componente JSX listo para usar
- **Vue** — componente Vue compatible
- **Angular** — componente Angular
- **Svelte** — componente Svelte

## Características
- ✅ 581+ logos disponibles (y creciendo)
- ✅ SVGs optimizados y limpios
- ✅ Búsqueda rápida por nombre
- ✅ Soporte multi-framework (React, Vue, Angular, Svelte)
- ✅ Open source (GitHub: 5k+ stars)
- ✅ Posibilidad de contribuir y agregar logos nuevos

## Cuándo usarlo
- Necesitas el logo de una tecnología o marca para tu proyecto
- Estás armando una sección de "tecnologías que usamos" o "integraciones"
- Documentación técnica con iconografía de herramientas
- Landing pages, portfolios, presentaciones
